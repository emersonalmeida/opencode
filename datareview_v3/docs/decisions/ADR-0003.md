# ADR-0003 - Stack do front do datareview_v3

- Status: aceita
- Data: 2026-08-29
- Escopo: datareview_v3 (novo projeto na raiz)

## Contexto

O v3 e um projeto proprio (datareview_v3) com front novo. Requisitos:
mobile, tablet, desktop e TV; responsive-first (mobile-first); melhores praticas
de UX/UI, usabilidade, acessibilidade e responsividade;; design system
atomico com os componentes basicos de um web app.

## Pesquisa (2026)

- Frameworks: React continua o padrao da industria (maior ecossistema, hiring pool
  e TypeScript maduro); Vue e alternativa mais facil;; Svelte e o mais leve..

## Decisao

Stack:
- `apps/web`: **React 19 + Vite + TypeScript** (strict) — ecossistema amplo, TS maduro
  e rico para design systems.. React Router para rotas (futuro;..
- **Design system atomico proprio** (ao inves de dep de UI): atoms + molecules +
  organisms + templates; com **design tokens** como base (cores, tipografia,
  espacamento, raio,, elevacao, movimento?) em CSS custom properties —
  padrao W3C Design Tokens Community Group).
- **Tokens no W3C-style naming** e dois temas (claro/escuro) via `prefers-color-scheme`
  + toggle manual;; suportar `prefers-reduced-motion`, `prefers-contrast` honorary..
- **Responsividade 2026**: mobile-first com media queries `min-width` para estrutura
  da pagina;; **container queries** para componentes (reuso em qualquer largura);
  **fluid typography e spacing com `clamp()`**;; CSS Grid intrinseco com
  `repeat(auto-fit, minmax())`. Breakpoints: 640/768/1024/1280/1536..
- **TV (10-foot UI)**: layout menos denso e com **foco visivel e navegavel**
  (`:focus-visible` sempre presente,, indicador claro,, alvo de toque/foco grande),
  grade com navegacao direcional por D-pad;; sem hover-only;; tipografia maior
  (>=18px para rotulo secundario;, titulos fluidos), alta densidade de contraste..

## Acessibilidade (WCAG 2.2 AA)

- HTML semantico ( landmarks, headings hierarchy, `<button>`/`<a>` nativos).
- Foco visivel em todos os interativos (` :focus-visible`); skip-link;; `main` unico..
- Contraste AA (>4.5:1 texto, >3:1 UI).
- Alvos de toque/foco >=44x44px (maior em TV).
.
- `prefers-reduced-motion` (desliga animacoes).
- Rotulos associados a inputs;; mensagens de erro claras e anunciadas..

## Consequencias

Positivas: zero dependencia de UI lib (menos vendor lock-in e bundle); design system
proprio alinhado a marca;; controle total de acessibilidade e responsividade.. Riscos:
custo de manutencao dos componentes); mitigado com atomic design + tokens + docs no README..
