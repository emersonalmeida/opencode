# ADR-0004 - Ativação é estado derivável (default do catálogo + overrides)

- Status: aceita
- Data: 2026-08-30
- Escopo: datareview_v5

## Contexto

O pedido: 8 fontes ativas por padrão, com opção de ativar mais. Um
campo booleano "ligado/desligado" fixo por fonte criaria duas fontes de
verdade ( catálogo + estado) e conflitaria com a regra "ativação por padrão".

## Decisão

- O catálogo declara `enabledByDefault: boolean` (8 fontes `true`; as
  demais 51 `false`, porém **todas catalogadas e prontas** para ativar).

- `computeEnabledSources(catalog, overrides)` é função pura: para cada fonte,
  `overrides[id] ?? enabledByDefault` — default primeiro,, override de usuário
  vence. Sem estado persistido fora do usuário: o front guarda só os overrides
  (localStorage), nunca a lista inteira.



## Consequências

Positivas: fonte nova com default sensato (false para extras, true para
prioritárias) = 0 mudança na lógica; a UI mostra badge "ativa por padrão";
a ordem padrão segue prioridade sem-auth. Riscos:overrides locais somem ao
trocar de navegador — aceitável para v5 (sem conta/multiusuário ainda).
